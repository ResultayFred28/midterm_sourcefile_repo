    Working on the exercises about stacks, queues, priority queues, and linked lists helped me understand
data structures better. I learned that each data structure has its own way of organizing and accessing 
data. Stacks use Last-In, First-Out (LIFO), queues use First-In, First-Out (FIFO), priority queues arrange 
data based on priority, and linked lists connect data using nodes. Through these exercises, 
I understood that choosing the right data structure depends on how the data needs to be stored and accessed.

One of the biggest challenges for me was working with linked lists, especially when adding and 
removing nodes. I had to carefully follow each step to make sure the nodes were connected correctly and 
that no errors occurred. I also found priority queues more challenging because I needed 
to compare values and place them in the correct order instead of simply adding them at the end.

Overall, these exercises helped me connect the concepts I learned in class with actual programming. 
I realized that data structures are not only about storing data. They are also important for 
making programs more organized, efficient, and easier to manage.
